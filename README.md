# userscripts

Personal userscripts for [Tampermonkey](https://www.tampermonkey.net/). Open a file's raw link to install it; each one points its update URL back here, so the extension pulls new versions by itself.

| Script | What it does |
|---|---|
| [bitwarden-icon-enabler](https://raw.githubusercontent.com/volkanncicek/userscripts/main/bitwarden-icon-enabler.user.js) | Makes Bitwarden offer autofill on the e-Devlet and GTU login fields |
| [enhanced-scroll-controls](https://raw.githubusercontent.com/volkanncicek/userscripts/main/enhanced-scroll-controls.user.js) | Scroll-to-bottom button and an endless-scroll toggle, turned on per site from the Tampermonkey menu |
| [force-page-visibility](https://raw.githubusercontent.com/volkanncicek/userscripts/main/force-page-visibility.user.js) | Makes the sites you turn it on for believe they are visible, so their background tabs keep running |
| [github-avif-preview](https://raw.githubusercontent.com/volkanncicek/userscripts/main/github-avif-preview.user.js) | Shows AVIF files inline in GitHub's file view |
| [github-mermaid-light-mode](https://raw.githubusercontent.com/volkanncicek/userscripts/main/github-mermaid-light-mode.user.js) | Renders GitHub Mermaid diagrams in light mode so custom colours survive dark mode |
| [google-map-preview-to-maps](https://raw.githubusercontent.com/volkanncicek/userscripts/main/google-map-preview-to-maps.user.js) | Opens Google Maps when you click the map preview in search results |
| [gtu-announcement-dates](https://raw.githubusercontent.com/volkanncicek/userscripts/main/gtu-announcement-dates.user.js) | Adds last-updated dates to GTU announcement lists |
| [instagram-gallery-photo-counter](https://raw.githubusercontent.com/volkanncicek/userscripts/main/instagram-gallery-photo-counter.user.js) | Shows "3 of 5" in Instagram galleries |
| [instagram-toolkit](https://raw.githubusercontent.com/volkanncicek/userscripts/main/instagram-toolkit.user.js) | Removes your Instagram comments, likes, reposts, story replies and reviews from before a date you pick |
| [linkedin-saved-posts-read-button](https://raw.githubusercontent.com/volkanncicek/userscripts/main/linkedin-saved-posts-read-button.user.js) | Read button on LinkedIn saved posts that opens the post in a new tab and greys out the row |
| [mf286r-rf-panel](https://raw.githubusercontent.com/volkanncicek/userscripts/main/mf286r-rf-panel.user.js) | Live RF dashboard, DNS setting and 4G lock for the ZTE MF286R modem's web UI |
| [nadirkitap-seller-info](https://raw.githubusercontent.com/volkanncicek/userscripts/main/nadirkitap-seller-info.user.js) | Shows the seller's city and a Google search link on Nadirkitap |
| [sahibinden-photo-downloader](https://raw.githubusercontent.com/volkanncicek/userscripts/main/sahibinden-photo-downloader.user.js) | Downloads every photo of a Sahibinden listing in order |
| [universal-tab-title-editor](https://raw.githubusercontent.com/volkanncicek/userscripts/main/universal-tab-title-editor.user.js) | Sets the tab title from the page heading on Gebze Technical University pages, so saved tab lists stay readable |
| [youtube-ask-gemini](https://raw.githubusercontent.com/volkanncicek/userscripts/main/youtube-ask-gemini.user.js) | Hands the current video to Gemini in one click |
| [youtube-chapter-title-expander](https://raw.githubusercontent.com/volkanncicek/userscripts/main/youtube-chapter-title-expander.user.js) | Shows full chapter titles in YouTube's chapters panel instead of truncating them |
| [youtube-resize-player](https://raw.githubusercontent.com/volkanncicek/userscripts/main/youtube-resize-player.user.js) | Shrinks the YouTube player so the title and date fit without scrolling |
| [youtube-resume-playback](https://raw.githubusercontent.com/volkanncicek/userscripts/main/youtube-resume-playback.user.js) | Resumes videos where you left off, even with watch history off |
| [youtube-subscription-tracker](https://raw.githubusercontent.com/volkanncicek/userscripts/main/youtube-subscription-tracker.user.js) | Marks which subscription videos you have opened |
| [youtube-volume-normalizer](https://raw.githubusercontent.com/volkanncicek/userscripts/main/youtube-volume-normalizer.user.js) | Raises quiet videos to YouTube's loudness target |

Scripts installed from elsewhere are listed in [third-party.md](third-party.md).
